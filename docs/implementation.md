# 个人项目展示站实施说明

用户授权：统一整理其他仓库的产品呈现及GitHub说明，汇总为公开个人作品站；私有项目仅展示脱敏介绍，不公开源码。署名沿用GitHub账号bxfzzti。

设计：苹果风格的浅灰底、留白、大标题、清晰状态与直接入口。两项可在线使用工具作为主视觉；三项公开Skill/工作流及一个私有项目使用独立介绍页。两个Fork单列并标注上游；三个空历史仓库只放历史列表。

实现：无依赖静态站；projects.mjs为经过确认的公开内容清单；build.mjs生成首页与详情页。assets目录放样式及交互。禁止把私有仓库名称、URL、截图、路径、运行数据、用户信息或密钥写入公开产物。

各公开仓库：保留技术实现和安装标识；重写README，原说明保存在根目录README.technical.md，避免相对链接改变。三项Skill仓库增加site/独立介绍页与Pages工作流。抽签只更新样式和导航，不改变抽样、存储和名单数据。

验收：检查静态链接、每项状态与入口、无私有标识、无虚构上线功能；本地桌面/手机交互；抽签测试；各GitHub Pages部署与HTTP内容核对。原业务完整测试不在纯展示更改后无意义重跑。
